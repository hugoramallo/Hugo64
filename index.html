Moves: press Space again in mid-air for a double jump, or jump again right as you land for chained double and triple jumps · run + C + Space = long jump · stand + C + Space = backflip · reverse direction while running + Space = side flip · jump into a wall, then Space = wall kick · C in the air = ground pound.
